# Project Title: Personal Blotter  

#### **Status:** In progress

### Project Overview: 
- A full-stack application that displays near-real-time updates in a simulated data displayed in tabular format through a flash visual value change indicator, with input of value change frequency and displayed change duration. 

### Steps to get the application starting: 
1. Clone the repository using the git clone command. 
2. Open terminal and open the project and the frontend folder inside.
3. Run command: npm install 
    - The command installs all the necessary packages and dependencies. 
4. Open backend folder of the folder in another terminal and run the command: npm start
    - This command starts the backend server. 
5. Open frontend folder in a separate folder and run the command: npm start.
    - This command starts the frontend server and redirects to the application.
